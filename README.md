An out-of-office auto-reply from an inbox that has started replying to itself — it tells you I'm away, and it will keep telling you until I'm back.

![Out of office](out-of-office.png)

## The entry

> This inbox now auto-replies to itself while I'm away; it just told you I'm away, and it will keep telling you until I'm back.

## Run it

```sh
python3 main.py
```

This writes the one-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
